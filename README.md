# AI Daily Journal Summarizer (PS #47)

## Problem Statement
Journaling without periodic review has little value because day-to-day notes stay scattered and emotional patterns go unnoticed. This application helps individuals log daily journal entries in a CSV file, tag each entry with a mood and score using an LLM, and review weekly mood trends, highlights, and a line chart in a simple web interface.

## How to Run
1. Clone the repository and navigate into the project folder:
   ```bash
   git clone [https://github.com/Skkiller01/llm-ps47-ADT23SOCB1185.git](https://github.com/Skkiller01/llm-ps47-ADT23SOCB1185.git)
   cd llm-ps47-ADT23SOCB1185

```

2. Create a `.env` file in the project root with your Gemini API key:
```env
GEMINI_API_KEY=your_api_key_here

```


3. Install dependencies and run the Streamlit app:
```bash
pip install -r requirements.txt
streamlit run app.py

```
